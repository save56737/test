# Tetris Pro - Ultimate Tetris Experience

یک بازی تتریس حرفه‌ای با تمام ویژگی‌های مدرن و سیستم تحلیل هوشمند Tetris Lab

## 🎮 ویژگی‌های اصلی

### گیم‌پلی حرفه‌ای
- ✅ 7-Bag Randomizer
- ✅ Hold Piece
- ✅ Ghost Piece
- ✅ Hard Drop / Soft Drop
- ✅ Wall Kick (SRS)
- ✅ T-Spin Detection
- ✅ Combo System
- ✅ Back-to-Back Bonus
- ✅ Lock Delay قابل تنظیم
- ✅ DAS و ARR قابل تنظیم
- ✅ Preview تا ۵ قطعه بعدی

### مودهای بازی
- Classic - تتریس سنتی
- Sprint - ۴۰ Line را سریع تمام کن
- Ultra - ۳ دقیقه بازی
- Marathon - تا Level 30
- Endless - بدون محدودیت
- Survival - هر ۳۰ ثانیه اتفاق بد
- Zen - بدون باخت، موسیقی آرام
- Daily Challenge - چالش روزانه
- Boss Mode - حالت ویژه

### Tetris Lab (سیستم تحلیل هوشمند)
- 📊 تحلیل کیفیت تصمیم‌ها (Accuracy Score)
- 🔍 شناسایی فرصت‌های از دست رفته
- 💡 تشخیص نقاط ضعف
- 📈 نمودار پیشرفت
- 🎯 پیشنهاد تمرین شخصی

### سیستم امتیازدهی حرفه‌ای
- Grade: C, B, A, S, SS, SSS, SSS+
- محاسبه بر اساس Combo, T-Spin, Perfect Clear, Efficiency

### شخصی‌سازی کامل
- ۴ Theme مختلف (Neon, Classic, Minimal, Nature)
- تنظیمات Accessibility (Color Blind, High Contrast)
- تنظیمات حرفه‌ای DAS, ARR, Lock Delay
- افکت‌های Screen Shake و Particles

### آمار و پروفایل
- Heatmap قرارگیری قطعات
- تاریخچه بازی‌ها
- بهترین رکوردها
- Leaderboard

## 🚀 نصب و اجرا

```bash
cd tetris-pro
npm install
npm run dev
```

بازی در آدرس `http://localhost:3000` باز می‌شود.

## 🎯 کنترل‌ها

| کلید | عملکرد |
|------|--------|
| ← → یا A D | حرکت چپ/راست |
| ↓ یا S | Soft Drop |
| ↑ یا W یا X | چرخش ساعت‌گرد |
| Z | چرخش پادساعت‌گرد |
| Space | Hard Drop |
| Shift یا C | Hold Piece |
| P یا Escape | Pause |

## 🏆 سیستم Grade

| Grade | حداقل امتیاز |
|-------|-------------|
| - | 0 |
| C | 1,000 |
| B | 3,000 |
| A | 6,000 |
| S | 10,000 |
| SS | 15,000 |
| SSS | 20,000 |
| SSS+ | 30,000 |

## 🔧 تنظیمات حرفه‌ای

- **DAS** (Delay Auto Shift): 50-500ms
- **ARR** (Auto Repeat Rate): 10-100ms  
- **Soft Drop Speed**: 1-20x
- **Lock Delay**: 300-1000ms
- **Rotation System**: SRS / ARS
